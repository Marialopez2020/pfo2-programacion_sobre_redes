Descripción del Proyecto

Este proyecto consiste en un servidor desarrollado en Flask que expone una API para el registro, inicio de sesión y visualización de tareas, implementando buenas prácticas de seguridad como el hasheo de contraseñas y almacenamiento en base de datos SQLite.

Endpoints de la API

  • POST /registro: Recibe un JSON con usuario y contraseña. Valida y guarda el usuario en la base de datos con su contraseña encriptada (hash).
  • POST /login: Valida credenciales contra la base de datos SQLite y retorna acceso exitoso.
  • GET /tareas: Retorna una página HTML con el panel de tareas.

Respuestas Conceptuales

1. ¿Por qué hashear contraseñas?

El hasheo de contraseñas es fundamental por seguridad. Si guardáramos las contraseñas en texto plano y la base de datos sufriera una filtración o acceso no autorizado, los datos de todos los usuarios quedarían expuestos de inmediato.

Las funciones de hash son unidireccionales (no se pueden revertir) y con el uso de sales (salt) protegen contra ataques de fuerza bruta y tablas arcoíris (rainbow tables). De esta manera, ni siquiera los administradores o desarrolladores pueden conocer la contraseña real de los usuarios.

2. Ventajas de usar SQLite en este proyecto

  • Sin configuración (Zero-configuration): No requiere instalar ni levantar un servicio o servidor de base de datos independiente como MySQL o PostgreSQL.
  • Portabilidad: Toda la base de datos se almacena en un único archivo local (database.db), lo que facilita enormemente mover o clonar el proyecto.
  • Ideal para desarrollo y aprendizaje: Viene integrada de forma nativa en la biblioteca estándar de Python (import sqlite3), siendo rápida y confiable para proyectos de escala pequeña a mediana.

Cómo Ejecutar el Proyecto

  1. Instalar dependencias: pip install -r requirements.txt
  2. Iniciar servidor: python servidor.py
  3. Ejecutar el cliente de consola: python cliente.py
